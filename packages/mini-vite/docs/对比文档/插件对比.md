# 插件对比

对比 mini-vite 与完整 Vite 的插件系统设计。

## 插件钩子对比

### mini-vite 实现的钩子

mini-vite 只实现了最核心的 5 个钩子：

```typescript
// mini-vite/src/node/plugin.ts
export interface Plugin extends RollupPlugin {
    name: string
    configureServer?: ServerHook       // 配置服务器
    resolveId?: (id, importer) => ...  // 解析模块路径
    load?: (id) => ...                 // 加载模块
    transform?: (code, id) => ...      // 转换模块
    transformIndexHtml?: (raw) => ...  // 转换 HTML
}
```

### Vite 完整的钩子

Vite 支持 Rollup 全套钩子 + Vite 特有钩子：

**Rollup 钩子（构建阶段）**

| 钩子 | 说明 | mini-vite |
|------|------|-----------|
| `options` | 修改 Rollup 配置 | ❌ |
| `buildStart` | 构建开始 | ❌ |
| `resolveId` | 解析模块路径 | ✅ |
| `load` | 加载模块 | ✅ |
| `transform` | 转换模块 | ✅ |
| `buildEnd` | 构建结束 | ❌ |
| `closeBundle` | 关闭 bundle | ❌ |

**Vite 特有钩子**

| 钩子 | 说明 | mini-vite |
|------|------|-----------|
| `config` | 修改 Vite 配置 | ❌ |
| `configResolved` | 配置解析完成 | ❌ |
| `configureServer` | 配置开发服务器 | ✅ |
| `transformIndexHtml` | 转换 HTML | ✅ |
| `handleHotUpdate` | 自定义 HMR 处理 | ❌ |

## 内置插件对比

|------|------|----------|
| `resolve` | 路径解析（相对路径、裸模块） | `plugins/resolve.ts` |

## 插件容器对比

### mini-vite 插件容器

mini-vite 实现了简化的插件容器：

```typescript
// mini-vite/src/node/server/pluginContainer.ts
class PluginContainer {
    // resolveId 钩子调用
    async resolveId(id, importer) { ... }
    
    // load 钩子调用
    async load(id) { ... }
    
    // transform 钩子调用
    async transform(code, id) { ... }
}
```

关键特点：
- 按顺序调用插件
- 返回首个非 null 结果
- 无钩子排序（`order: 'pre' | 'post'`）

### Vite 插件容器

Vite 的插件容器更复杂：

```typescript
// vite/src/node/server/pluginContainer.ts
class PluginContainer {
    // 钩子排序（pre、normal、post）
    getSortedPlugins(hookName)
    
    // 并行处理能力
    parallelize(hooks)
    
    // 完整的错误处理
    handleHookError()
    
    // 钩子上下文
    context: PluginContext
}
```

关键特点：
- 支持 `order: 'pre' | 'post' | null` 排序
- 支持并行钩子执行
- 完整的 Rollup 插件上下文
- 更完善的错误处理

## 插件开发对比

### mini-vite 插件示例

```typescript
// 简单插件
export function myPlugin(): Plugin {
    return {
        name: 'my-plugin',
        transform(code, id) {
            if (id.endsWith('.custom')) {
                return { code: transformCustom(code) }
            }
            return null
        }
    }
}
```

### Vite 插件示例

```typescript
// 完整插件
export function myVitePlugin(): Plugin {
    return {
        name: 'vite-plugin-my',
        // Vite 特有钩子
        config(config) {
            return { define: { MY_CONST: '"value"' } }
        },
        configResolved(resolvedConfig) {
            console.log('Config resolved!')
        },
        configureServer(server) {
            server.middlewares.use((req, res, next) => {
                // 自定义中间件
                next()
            })
        },
        // Rollup 钩子
        resolveId(id, importer) {
            if (id === 'virtual:my-module') {
                return id
            }
        },
        load(id) {
            if (id === 'virtual:my-module') {
                return 'export const msg = "Hello"'
            }
        },
        transform(code, id) {
            if (id.endsWith('.custom')) {
                return { code: transformCustom(code) }
            }
        },
        // HMR 钩子
        handleHotUpdate({ file, server, modules }) {
            if (file.endsWith('.custom')) {
                return []
            }
        }
    }
}
```

## 学习要点

1. **5 个核心钩子覆盖了 80% 的开发场景**
2. **`resolveId -> load -> transform` 是模块处理的主链路**
3. **插件排序**在复杂场景下很重要（pre/post）
4. **Vite 特有钩子**提供了配置、HMR 等扩展能力
