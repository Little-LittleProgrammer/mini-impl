# 架构对比

对比 mini-vite 与完整 Vite 的架构设计。

## 核心架构

### mini-vite 架构

```
mini-vite/
├── src/node/
│   ├── cli.ts              # CLI 入口（仅 dev 命令）
│   ├── server/
│   │   ├── index.ts        # 开发服务器（connect）
│   │   ├── middlewares/    # 中间件
│   │   ├── hmr.ts          # HMR 服务端
│   │   └── pluginContainer.ts  # 插件容器
│   ├── plugins/
│   │   ├── resolve.ts      # 路径解析
│   │   ├── esbuild.ts      # esbuild 编译
│   │   ├── importAnalysis.ts  # 导入分析
│   │   ├── cjs.ts          # CommonJS 支持
│   │   ├── css.ts          # CSS 处理
│   │   └── hmr.ts          # HMR 插件
│   ├── optimizer/          # 预构建
│   ├── transformRequest.ts # 模块转换流程
│   └── plugin.ts           # 插件接口定义
```

### Vite 架构

```
vite/
├── packages/
│   ├── vite/
│   │   ├── src/
│   │   │   ├── node/
│   │   │   │   ├── cli.ts          # CLI（dev/build/preview）
│   │   │   │   ├── server/         # 开发服务器
│   │   │   │   │   ├── index.ts
│   │   │   │   │   ├── middlewares/ # 多种中间件
│   │   │   │   │   ├── hmr.ts
│   │   │   │   │   └── moduleGraph.ts
│   │   │   │   ├── builder/        # 生产构建（rollup）
│   │   │   │   ├── optimizer/      # 预构建
│   │   │   │   ├── plugins/        # 内置插件（20+）
│   │   │   │   ├── config.ts       # 配置解析
│   │   │   │   ├── env.ts          # 环境变量
│   │   │   │   └── ssr/            # SSR 支持
│   │   │   │   └── preview.ts      # 预览服务器
│   │   │   │   └── logger.ts       # 日志系统
│   │   │   │   └── utils.ts        # 工具函数
│   ├── rollup/                     # Vite 内置 rollup 版本
│   ├── plugin-vue/                 # Vue 插件
│   ├── plugin-vue-jsx/             # Vue JSX 插件
│   ├── plugin-react/               # React 插件
│   └── create-vite/                # 项目脚手架
```

## 架构差异对比

### 1. CLI 命令

| 方面 | mini-vite | Vite |
|------|-----------|------|
| 命令数量 | 仅 `dev` | `dev`、`build`、`preview` |
| 参数支持 | 无 | 丰富的 CLI 参数 |
| 配置文件 | 无 | `vite.config.ts/js/mjs` |

### 2. 开发服务器

| 方面 | mini-vite | Vite |
|------|-----------|------|
| HTTP 框架 | connect | connect |
| 中间件数量 | ~4 个 | ~15 个 |
| HTTPS 支持 | 无 | 支持 |
| HTTP/2 支持 | 无 | 支持 |
| 代理功能 | 无 | `server.proxy` 配置 |
| CORS 支持 | 无 | `server.cors` 配置 |

### 3. 生产构建

| 方面 | mini-vite | Vite |
|------|-----------|------|
| 构建能力 | 无 | 基于 Rollup |
| CSS 分离 | 无 | 支持 |
| 代码分割 | 无 | 支持 |
| 压缩优化 | 无 | esbuild 压缩 |
| Source Map | 无 | 支持 |

### 4. 模块图

| 方面 | mini-vite | Vite |
|------|-----------|------|
| 基础结构 | 有（简化版） | 有（完整版） |
| SSR 模块图 | 无 | 有独立处理 |
| 手动边界控制 | 无 | `import.meta.hot.accept` 边界控制 |

## 核心流程对比

### mini-vite 启动流程

```
CLI 启动
    ↓
创建开发服务器（connect）
    ↓
注册内置插件
    ↓
执行预构建（扫描 + 打包）
    ↓
启动 HTTP 服务
    ↓
等待浏览器请求
```

### Vite 启动流程

```
CLI 启动
    ↓
解析配置文件（vite.config.*）
    ↓
加载环境变量（.env.*）
    ↓
创建开发服务器（connect）
    ↓
注册内置插件 + 用户插件
    ↓
执行预构建（扫描 + 打包）
    ↓
启动 HTTP 服务 + WebSocket
    ↓
打印启动信息
    ↓
等待浏览器请求
```

## 学习要点

1. **mini-vite 保留了 Vite 的核心请求处理链路**：`resolveId -> load -> transform`
2. **插件系统是最关键的抽象**，mini-vite 实现了核心钩子
3. **预构建机制**是 Vite 与纯 ESM 开发的关键差异点
4. **生产构建是 Vite 完整能力的重要组成**，mini-vite 未实现
