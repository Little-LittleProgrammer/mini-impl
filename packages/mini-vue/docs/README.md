这套文档按源码架构重新整理，只解释当前仓库已经实现或明确留下边界的内容。阅读时建议把它当作 Vue 3 核心模型的教学实现，而不是完整 Vue 的 API 手册。

## 各部分关注点

- `01-架构`：包分层、依赖方向、运行时与编译器如何接起来。
- `02-响应式`：`reactive`、`ref`、`computed`、`watch`、`effect` 的依赖收集与触发。
- `03-运行时`：`VNode`、渲染器、组件实例、调度器、生命周期、DOM 适配层。
- `04-编译时`：`parse -> transform -> codegen` 如何把模板变成 render 函数字符串。
- `05-与Vue3.6完整版区别`：当前 mini-vue 与完整 Vue 3.5 稳定版、Vue 3.6 beta 路线之间的能力差距。

## 重要边界

- 当前 npm `vue@latest` 是 `3.5.38`，`3.6.0-beta.15` 在 `beta` dist-tag 下，不是稳定 latest。
- 本仓库的 `mini-vue` 实现了 Vue 经典 VDOM 路线的骨架，没有实现 Vue 3.6 beta 中出现的 `runtime-vapor` 路线。
- 文档中的“Vue 3.6”指 `3.6.0-beta.x` 已公开包信息和由完整 Vue 3 继承而来的能力，不把 beta 细节写成稳定承诺。
