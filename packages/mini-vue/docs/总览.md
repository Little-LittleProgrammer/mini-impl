# mini-vue 总览

mini-vue 是一个按 Vue 3 分层方式拆出来的教学实现。它重点保留三条主线：响应式系统如何发现状态变化，运行时如何把 VNode patch 到 DOM，编译器如何把模板变成 render 函数。

## 你应该先建立的模型

```text
template 或 render
  -> render 执行得到 VNode
  -> renderer.patch 根据 VNode 类型挂载或更新
  -> 组件 render 被 ReactiveEffect 包裹
  -> reactive/ref 写入触发 trigger
  -> scheduler 合并更新
  -> 重新 render 并 patch DOM
```

这条链路里，响应式系统不直接操作 DOM，编译器也不直接更新 DOM。它们通过运行时的 render 函数和组件更新 effect 接在一起。

## 包结构

```text
packages/mini-vue/packages
├─ shared
├─ reactivity
├─ runtime-core
├─ runtime-dom
├─ compiler-core
├─ compiler-dom
├─ vue-compat
└─ vue
```

## 模块职责

| 包 | 当前职责 | 关键文件 |
| --- | --- | --- |
| `shared` | 公共工具、`ShapeFlags`、class 规范化、显示字符串转换 | `packages/mini-vue/packages/shared/src` |
| `reactivity` | `reactive`、`ref`、`computed`、`effect` 的底层依赖系统 | `packages/mini-vue/packages/reactivity/src` |
| `runtime-core` | VNode、组件实例、渲染器、调度器、生命周期、watch | `packages/mini-vue/packages/runtime-core/src` |
| `runtime-dom` | 浏览器 DOM host 操作和 props patch | `packages/mini-vue/packages/runtime-dom/src` |
| `compiler-core` | 模板解析、AST 转换、代码生成 | `packages/mini-vue/packages/compiler-core/src` |
| `compiler-dom` | 当前只是 `compiler-core` 的薄封装 | `packages/mini-vue/packages/compiler-dom/src/index.ts` |
| `vue-compat` | 把编译器注册到运行时，提供运行时模板编译 | `packages/mini-vue/packages/vue-compat/src/index.ts` |
| `vue` | 聚合导出所有公开 API | `packages/mini-vue/packages/vue/src/index.ts` |

## 当前已经实现的核心能力

- `reactive`：基于 `Proxy` 的对象响应式，支持按访问递归代理。
- `ref`：通过 `.value` 容器实现独立值响应式。
- `computed`：基于 `_dirty` 的惰性求值和缓存。
- `watch`：支持 reactive source、`deep`、`immediate` 的窄子集。
- `VNode`：支持元素、组件、文本、注释、Fragment 的基本表达。
- `renderer`：支持元素挂载、props patch、组件挂载/更新、keyed children diff 主干。
- `scheduler`：通过微任务队列做更新合并和去重。
- `compiler`：支持元素、文本、插值、基础属性、`v-if`、相邻文本合并、render code 生成。

## 当前明显没有实现的内容

- 完整组件模型：props 初始化、emit、slots、provide/inject、组件更新判定等。
- 完整响应式 API：`readonly`、`shallowReactive`、`toRef`、`watchEffect`、effect cleanup 等。
- 完整 diff/卸载：`patchChildren` 仍有 TODO，`unmount` 没有递归组件清理。
- 完整模板语法：`v-for`、`v-model`、事件绑定、动态属性、slot 编译、组件解析等。
- 编译优化闭环：没有 block tree、patch flags、静态提升运行时协同。
- SFC、SSR、hydration、Teleport、Transition、Suspense、KeepAlive。
- Vue 3.6 beta 的 Vapor Mode / `runtime-vapor` 路线。
