# 编译时总览

编译器负责把模板字符串变成 render 函数字符串。当前实现重点展示 `parse -> transform -> codegen` 三段式流水线。

## 源码入口

- `packages/mini-vue/packages/compiler-core/src/compile.ts`
- `packages/mini-vue/packages/compiler-core/src/parse.ts`
- `packages/mini-vue/packages/compiler-core/src/ast.ts`
- `packages/mini-vue/packages/compiler-core/src/transform.ts`
- `packages/mini-vue/packages/compiler-core/src/codegen.ts`
- `packages/mini-vue/packages/compiler-core/src/transforms/transformElement.ts`
- `packages/mini-vue/packages/compiler-core/src/transforms/transformText.ts`
- `packages/mini-vue/packages/compiler-core/src/transforms/vIf.ts`
- `packages/mini-vue/packages/compiler-dom/src/index.ts`

## 总流程

```text
baseCompile(template)
  -> baseParse(template.trim())
  -> transform(ast, {
       nodeTransforms: [transformElement, transformText, transformIf]
     })
  -> generate(ast)
  -> { ast, code }
```

`compiler-dom` 当前只是调用 `baseCompile`，没有 DOM 平台特有转换。

## parse 阶段

`baseParse` 会把模板解析为 AST：

```text
template string
  -> ParserContext { source }
  -> parseChildren
  -> parseElement / parseInterpolation / parseText
  -> createRoot(children)
```

当前解析器支持：

- 元素标签。
- 文本。
- 插值 `{{ msg }}`。
- 基础属性。
- 基础指令节点识别，例如 `v-if`。

## transform 阶段

`transform` 使用深度优先遍历：

```text
进入节点
  -> 执行 nodeTransforms，收集退出函数
遍历子节点
退出节点
  -> 倒序执行退出函数
```

当前内置转换：

- `transformElement`：把元素转换成 VNode call 的 codegenNode。
- `transformText`：合并相邻文本和插值，生成复合表达式。
- `transformIf`：把 `v-if` 转成 JS 条件表达式。

## codegen 阶段

`generate(ast)` 会输出一段函数字符串：

```text
const _Vue = Vue

return function render(_ctx, _cache) {
  with (_ctx) {
    const { ...helpers } = _Vue
    return ...
  }
}
```

运行时模板编译时，`vue-compat` 会用：

```ts
new Function(code)()
```

把这段字符串变成真正的 render 函数。

## 支持能力

当前编译器能表达：

- 单根元素的基本模板。
- 文本 children。
- 插值表达式。
- 相邻文本/插值拼接。
- 基础属性节点解析。
- `v-if` 的基础三元表达式输出。
- `createElementVNode`、`toDisplayString`、`createCommentVNode` 等 helper 收集。

## 当前明显不支持

- `v-for`
- `v-on`/`@click` 的完整表达式生成
- `v-bind`/`:prop` 的动态 props 生成
- `v-model`
- `v-show`
- slot 编译
- 组件解析
- 多根 Fragment 编译
- SFC 编译
- source map、错误恢复、位置范围
- block tree、patch flags、静态提升与运行时优化闭环

另外，`baseCompile` 当前仍有 `console.log(ast)` 调试输出，实际使用时会污染控制台。
