# 解析器

解析器把模板字符串转换为基础 AST。入口是 `baseParse(content)`。

## 主流程

```text
baseParse(content)
  -> createParserContext(content)
  -> parseChildren(context, [])
  -> createRoot(children)
```

解析器上下文只有一个核心字段：

```ts
source: string
```

解析过程不断从 `context.source` 头部消费字符。

## parseChildren

`parseChildren(context, ancestors)` 会循环解析直到结束：

```text
如果 source 以 "{{" 开头
  -> parseInterpolation
否则如果 source 以 "<" + 字母开头
  -> parseElement
否则
  -> parseText
```

`ancestors` 用来判断当前是否遇到祖先标签的结束标签。

## 解析插值

模板：

```html
{{ msg }}
```

会生成：

```text
INTERPOLATION
  -> SIMPLE_EXPRESSION(content: "msg", isStatic: false)
```

处理步骤：

```text
消费 "{{"
找到 "}}"
取中间内容并 trim
消费 "}}"
```

## 解析元素

模板：

```html
<div id="app">hello</div>
```

处理步骤：

```text
parseTag(Start)
  -> 解析标签名
  -> 解析属性和指令
  -> 消费 ">" 或 "/>"
parseChildren
parseTag(End)
```

元素节点会包含：

- `type: ELEMENT`
- `tag`
- `tagType`
- `props`
- `children`

## 解析属性和指令

普通属性：

```html
<div id="app">
```

生成 `ATTRIBUTE` 节点。

指令：

```html
<div v-if="ok">
```

生成 `DIRECTIVE` 节点：

```text
name: "if"
exp: SIMPLE_EXPRESSION(content: "ok")
```

当前指令解析只抽出基础 `name` 和表达式，参数、修饰符仍是 TODO。

## 解析文本

文本解析会找最近的结束 token：

- `<`
- `{{`

从当前位置截取到最近 token 前作为文本节点。

## 当前解析器边界

- 没有完整 HTML tokenizer。
- 没有注释解析。
- 没有 CDATA、raw text、RCDATA 模式。
- 没有实体解码。
- 没有完整错误恢复。
- 没有准确 source location。
- 自闭合标签只消费语法，不做平台语义校验。
- 指令参数和修饰符还未实现。

这个解析器适合理解“模板如何进入 AST”，不适合作为完整 HTML/Vue 模板解析器。
